# Letras extras — complemento do IOkê / Extra lyrics — IOkê add-on

**Português.** Mais fontes de letras sincronizadas para o IOkê: **NetEase** (muitas com o tempo de cada palavra) e
**Musixmatch** (pelo syncedlyrics). As letras aparecem na escolha da letra e na escolha automática, junto com o
LRCLIB. Instale em Configurações → Complementos, colando o link deste repositório. Dá para desligar cada fonte nas
opções do complemento.

**English.** More synced lyrics sources for IOkê: **NetEase** (many with the timing of each word) and
**Musixmatch** (through syncedlyrics). The lyrics show up in the lyrics picker and in the automatic choice, alongside
LRCLIB. Install in Settings → Add-ons by pasting this repository's link. Each source can be turned off in the add-on's
options.
