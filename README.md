# Letras extras — complemento do IOkê / Extra lyrics — IOkê add-on

**Português.** Mais letras sincronizadas para o IOkê, do **NetEase** (muitas com o tempo de cada palavra). Elas
aparecem na escolha da letra e na escolha automática, junto com as do LRCLIB, em ordem de qualidade. Instale em
Configurações → Complementos, colando o link deste repositório.

O Musixmatch saiu na versão 1.1.0: ele passou a recusar o acesso sem conta e não devolvia mais nenhuma letra.

**English.** More synced lyrics for IOkê, from **NetEase** (many with the timing of each word). They show up in the
lyrics picker and in the automatic choice, alongside LRCLIB's, in order of quality. Install in Settings → Add-ons by
pasting this repository's link.

Musixmatch was removed in version 1.1.0: it started refusing access without an account and no longer returned any
lyrics.
